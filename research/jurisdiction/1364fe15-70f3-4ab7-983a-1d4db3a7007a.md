# SADC Treaty 1992 (Southern African Development Community)

The Treaty of the Southern African Development Community (SADC Treaty) is a regional supranational meta-framework foundational-SADC-treaty framework adopted by the 10 Southern African states in Windhoek — structurally distinctive globally as the only modern Southern African regional supranational binding-treaty framework operating on formal Southern-Africa framework (SADC Treaty signed 17 August 1992 in Windhoek Namibia + effective 30 September 1993 + SADCC predecessor founded 1 April 1980 in Lusaka — formal foundational SADC treaty framework establishing comprehensive SADC organisation framework, distinct from rest-of-modern-regional-African-treaty frameworks which operate on different geographic scopes, structurally distinctive globally as the only modern Southern African regional supranational binding-treaty framework operating formal Southern-Africa framework + only modern African regional supranational binding-treaty framework operating formal post-apartheid framework via SADCC predecessor framework framing as Frontline States vs apartheid South Africa + South Africa joined 29 August 1994 after end-of-apartheid framework + English-French-Portuguese trilingual framework), as the central jurisdiction of the formal SADC Tribunal Suspension framework (SADC Tribunal established 2005 by 2000 SADC Protocol on Tribunal + suspended 2010 by SADC Summit + replaced by 2014 Protocol on Tribunal granting only state-state jurisdiction stripping individual-petition framework — formal foundational SADC judicial-framework-stripped framework, structurally distinctive globally as the only modern regional supranational binding-treaty framework operating formal court-suspended-stripped-of-individual-petition-jurisdiction framework following adverse rulings against Zimbabwe land-reform framework in Mike Campbell case 2008), as the central jurisdiction of the formal SADC Free Trade Area framework (SADC Protocol on Trade signed 24 August 1996 + SADC Free Trade Area FTA launched 17 August 2008 in Sandton South Africa providing formal Southern-Africa-regional free-trade framework — formal foundational Southern-Africa-regional free-trade framework, structurally distinctive globally as the only modern Southern African regional supranational binding-treaty framework operating formal regional free-trade framework with 13 of 16 SADC member states participating), and as the central jurisdiction of the formal SADC Organ on Politics + Defence + Security Co-operation framework (SADC Organ on Politics, Defence and Security Co-operation OPDS established 28 June 1996 + SADC Protocol on Politics Defence and Security Co-operation signed 14 August 2001 + effective 2 March 2004 providing formal Southern-Africa-regional security framework — formal foundational Southern-Africa-regional security framework, structurally distinctive globally as the only modern Southern African regional supranational binding-treaty framework operating formal regional security framework with operational mandate framework via SAMIM Mozambique 2021-2025 + SAMIDRC DR Congo 2023-2024 framework). The SADC Treaty is binding upon 16 SADC member states as of 2026 (Angola + Botswana + Comoros + DRC + Eswatini + Lesotho + Madagascar + Malawi + Mauritius + Mozambique + Namibia + Seychelles + South Africa + Tanzania + Zambia + Zimbabwe) — comprehensive Southern African regional coverage framework. The Treaty is silent on 'parental alienation' as a statutory label, though formal SADC Protocol on Gender and Development 2008 framework operates substantial intersection with parental-alienation framework via formal Southern-Africa-regional cross-border-children's-rights framework. The SADC Summit + SADC Council of Ministers + SADC Secretariat + SADC Tribunal (suspended-and-replaced framework) + SADC Parliamentary Forum + SADC Organ on Politics Defence and Security are the formal SADC bodies; national-level apex courts operate as judicial bodies.
