# IMF Articles of Agreement 1944 (International Monetary Fund)

The Articles of Agreement of the International Monetary Fund (IMF Articles of Agreement) is a global supranational meta-framework foundational-IMF-treaty framework adopted by the 44 founding states at Bretton Woods — structurally distinctive globally as the only modern global supranational binding-treaty framework operating on formal international-monetary-cooperation framework + foundational Bretton Woods framework alongside World Bank framework (IMF Articles of Agreement adopted 22 July 1944 at Bretton Woods Conference in Bretton Woods New Hampshire USA by 44 founding states + effective 27 December 1945 + IMF operations began 1 March 1947 — formal foundational IMF treaty framework establishing comprehensive IMF organisation framework, distinct from rest-of-modern-international-treaty frameworks which operate on different substantive areas, structurally distinctive globally as the only modern global supranational binding-treaty framework operating on formal international-monetary-cooperation framework + foundational Bretton Woods framework alongside World Bank framework + only modern global supranational binding-treaty framework operating formal weighted-voting framework via quota-based-voting framework + only modern global supranational binding-treaty framework operating formal SDR Special Drawing Rights framework + only modern global supranational binding-treaty framework operating formal IMF Conditionality framework + only modern global supranational binding-treaty framework operating formal Soviet-non-participation framework via Soviet Union signed but never ratified IMF Articles of Agreement framework + Cold War-era unique framework), as the central jurisdiction of the formal IMF Special Drawing Rights SDR framework (IMF Special Drawing Rights SDR established 1969 via First Amendment to IMF Articles of Agreement effective 28 July 1969 providing formal supplementary international reserve asset framework — formal foundational IMF SDR framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal supplementary international reserve asset framework + only modern global supranational binding-treaty framework operating formal currency basket framework with USD + EUR + JPY + GBP + CNY effective 1 October 2016 framework), as the central jurisdiction of the formal IMF Conditionality framework (IMF Conditionality framework providing formal conditional-lending framework + Structural Adjustment Programmes SAPs framework + Stand-By Arrangements SBA framework + Extended Fund Facility EFF framework + Poverty Reduction and Growth Trust PRGT framework + Resilience and Sustainability Trust RST framework effective 2022 — formal foundational IMF Conditionality framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal Conditionality framework), and as the central jurisdiction of the formal IMF Quota Reform framework (IMF Quota Reform framework providing formal voting-power redistribution framework via 14th General Review of Quotas effective 26 January 2016 + 15th General Review concluded 13 February 2020 + 16th General Review concluded 15 December 2023 — formal foundational IMF Quota Reform framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal voting-power redistribution framework with operational Quota Reform framework including BRICS Plus emerging-economies share increase framework). The IMF Articles of Agreement is binding upon 191 IMF member states as of 2026 — substantial universal coverage framework with Andorra + Cuba + North Korea + Liechtenstein + Monaco + Nauru + Vatican non-members framework.
