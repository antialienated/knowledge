# AIIB Articles of Agreement 2015 (Asian Infrastructure Investment Bank)

The Articles of Agreement of the Asian Infrastructure Investment Bank (AIIB Articles of Agreement) is a global supranational meta-framework foundational-AIIB-treaty framework adopted by the 57 founding states in Beijing — structurally distinctive globally as the only modern China-led global supranational binding-treaty framework operating on formal infrastructure-investment-financing framework + first modern non-Bretton-Woods global multilateral development bank framework (AIIB Articles of Agreement signed 29 June 2015 in Beijing China by 57 Prospective Founding Members + effective 25 December 2015 + AIIB operations began 16 January 2016 — formal foundational AIIB treaty framework establishing comprehensive AIIB organisation framework, distinct from rest-of-modern-international-development-finance frameworks which operate under Bretton Woods framework, structurally distinctive globally as the only modern China-led global supranational binding-treaty framework + first modern non-Bretton-Woods global multilateral development bank framework + only modern global supranational binding-treaty framework operating formal infrastructure-investment-financing framework + only modern global supranational binding-treaty framework operating formal Asia-Pacific-focus-with-non-regional-membership framework + only modern global supranational binding-treaty framework operating formal China-veto-power framework via 26.06% voting share framework + only modern global supranational binding-treaty framework operating formal BRI-Belt-and-Road-Initiative complementary framework + only modern global supranational binding-treaty framework operating formal US-non-participation framework via US lobbied allies against joining framework + only modern global supranational binding-treaty framework operating formal Japan-non-participation framework via Japan-non-AIIB-member framework alongside US-Japan-led-ADB framework), as the central jurisdiction of the formal AIIB Triple-A Credit Rating + Operating Triple-A Credit Rating framework (AIIB obtained Triple-A AAA credit rating from Moody's + Fitch + S&P 2017 — formal foundational AIIB Triple-A credit-rating framework, structurally distinctive globally as the only modern China-led global multilateral development bank operating formal Triple-A credit rating from all three major credit-rating agencies framework + only modern non-Bretton-Woods global multilateral development bank operating formal Triple-A credit rating framework), as the central jurisdiction of the formal AIIB Climate Finance 50% framework (AIIB Climate Finance 50% framework adopted October 2020 + AIIB Corporate Strategy 2030 adopted September 2020 providing formal 50% climate-finance share by 2025 framework — formal foundational AIIB Climate Finance 50% framework, structurally distinctive globally as the only modern China-led global multilateral development bank operating formal 50% climate-finance framework + first major global multilateral development bank to commit to 50% climate-finance framework), and as the central jurisdiction of the formal AIIB Member Expansion 57 to 110 framework (AIIB Member Expansion framework from 57 Prospective Founding Members 2015 + 81 members 2018 + 110 members 2024 framework — formal foundational AIIB Member Expansion framework, structurally distinctive globally as the only modern China-led global multilateral development bank operating formal nearly-doubled-membership-in-eight-years framework). The AIIB Articles of Agreement is binding upon 110 AIIB member states + 17 AIIB prospective members as of 2026 — substantial Asia-Pacific + non-regional coverage framework with notable non-members United States + Japan + Mexico framework. The Articles are silent on 'parental alienation' as a statutory label, though formal AIIB Climate Finance + infrastructure-investment-financing framework operates limited intersection with parental-alienation framework via formal Asia-Pacific cross-border-infrastructure framework not dire
