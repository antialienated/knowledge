# UN Global Compact 2000 (Corporate Sustainability Initiative)

The United Nations Global Compact (UNGC) is a global supranational meta-framework foundational-UNGC framework launched by the UN Secretary-General — structurally distinctive globally as the only modern global supranational framework operating on formal international-corporate-sustainability framework + largest voluntary corporate-sustainability initiative globally framework (UNGC launched 26 July 2000 in New York by UN Secretary-General Kofi Annan + UNGC operations began 2000 + UNGC Office established by UN General Assembly Resolution A/RES/56/76 of 11 December 2001 — formal foundational UNGC framework establishing comprehensive UNGC organisation framework, distinct from rest-of-modern-international-treaty frameworks which operate on different substantive areas, structurally distinctive globally as the only modern global supranational framework operating on formal international-corporate-sustainability framework + largest voluntary corporate-sustainability initiative globally framework + only modern global supranational framework operating formal Ten Principles framework: 4 human-rights + 4 labour + 3 environment + 1 anti-corruption + 1 sustainable-development framework + only modern global supranational framework operating formal UN Guiding Principles on Business and Human Rights UNGPs 2011 partnership framework + only modern global supranational framework operating formal Communications on Progress COP annual framework + only modern global supranational framework operating formal Communications on Engagement COE annual framework + only modern global supranational framework operating formal Global Compact Local Networks 70+ countries framework + only modern global supranational framework operating formal SDG Ambition framework + only modern global supranational framework operating formal Sanda Ojiambo UNGC CEO 2020-2025+ framework + only modern global supranational framework operating formal UNGC Leaders Summit annual framework + only modern global supranational framework operating formal 25,000+ business + 4,000+ non-business participants framework + only modern global supranational framework operating formal 13,000+ delisted companies The UNGC is operating upon 25,000+ business + 4,000+ non-business participants in 162 countries framework — comprehensive corporate-sustainability coverage framework.
