# Northern Nigerian Sharia Framework (12-State Sharia Framework)

The Northern Nigerian Sharia Framework (formally 12-State Sharia Framework) is a Sub-Saharan African mixed common-law/Sharia-customary supranational meta-framework operating across 12 constituent states of the Federal Republic of Nigeria — structurally distinctive globally as the only modern sub-national Sharia framework operating across multiple constituent states of a single federal sovereign state (12 Northern Nigerian states + Federal Capital Territory framework: Bauchi + Borno + Gombe + Jigawa + Kaduna + Kano + Katsina + Kebbi + Niger + Sokoto + Yobe + Zamfara — formal multi-state Sharia framework adopted incrementally 1999-2002 with Zamfara State Sharia Penal Code Law 1999 effective 27 January 2000 establishing template framework + 11 subsequent Northern Nigerian state Sharia frameworks 2000-2002, distinct from rest-of-modern-sub-national-Sharia frameworks operating in single sub-national territories like Aceh + Brunei state-equivalent frameworks), as the central jurisdiction of the most significant modern Christian-Muslim sub-national legal-framework tension globally (Sharia framework 1999-2002 adoption catalysed 2000 Kaduna riots ~2,000-5,000 deaths + 2001-2010 Plateau State sectarian-violence framework ~5,000 cumulative deaths + 2009-2026 Boko Haram insurgency framework ~50,000-100,000 cumulative deaths + Lake Chad Basin Crisis framework — most significant modern Christian-Muslim sub-national legal-framework tension globally), as the only modern Sharia framework operating formal Hisbah religious-police framework with parallel formal civilian-government framework (Hisbah Boards established in Kano + Zamfara + Sokoto + other Northern Nigerian states 2000-2003 — formal Sharia-enforcement police framework operating in parallel with formal civilian-government police framework, distinct from rest-of-modern-Sharia-frameworks operating without formal parallel religious-police framework), and as the central jurisdiction of one of the most significant modern legal-pluralism frameworks globally (formal three-tier legal-pluralism framework: Nigerian Federal Constitution 1999 + State Sharia Penal Code framework + State Customary Law framework operating across same territorial framework — only modern formal three-tier legal-pluralism framework globally). The Northern Nigerian Sharia Framework historically operated under Sokoto Caliphate 1804-1903 + British Northern Nigeria Protectorate 1900-1914 + British Nigeria framework 1914-1960 + Northern Nigeria Region 1954-1967 + Nigerian Federal States 1967-1999 + Sharia Framework 1999-2002+. The Northern Nigerian Sharia Framework comprises ~12 states of Nigerian federal framework with a combined population of ~95-100 million. Family-law framework operates under a dual federal Nigerian common-law framework (Nigerian Marriage Act 1914) + state-level Sharia Personal Status framework + State Customary Law framework. The Sharia Courts of Appeal (12 state-level) are the apex regional Sharia courts; the Court of Appeal of Nigeria + Supreme Court of Nigeria are the apex federal courts. Northern Nigerian Sharia Framework is silent on 'parental alienation' as a statutory label. Nigeria is a Hague Convention 1980 signatory and party (acceded 14 February 2024 effective 1 May 2024) — Northern Nigerian Sharia Framework is governed by Nigerian Hague-Convention-1980 framework.
