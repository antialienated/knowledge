# OECS Revised Treaty of Basseterre 2010 (Organisation of Eastern Caribbean States)

The Revised Treaty of Basseterre Establishing the Organisation of Eastern Caribbean States Economic Union (OECS Revised Treaty) is a regional supranational meta-framework foundational-OECS-treaty framework adopted by the 6 founding Eastern Caribbean states in Saint Lucia — structurally distinctive globally as the only modern Eastern Caribbean regional supranational binding-treaty framework operating on formal Eastern-Caribbean-Economic-Union framework + only modern regional supranational binding-treaty framework operating formal Economic-Union framework with formal monetary-union framework via Eastern Caribbean Currency Union ECCU framework (OECS Revised Treaty signed 18 June 2010 in Saint Lucia + effective 21 January 2011 + original Treaty of Basseterre signed 18 June 1981 in Basseterre Saint Kitts and Nevis founding OECS — formal foundational revised OECS treaty framework establishing comprehensive OECS organisation framework, distinct from rest-of-modern-regional-Caribbean-treaty frameworks which operate on free-trade-area or common-market frameworks, structurally distinctive globally as the only modern Eastern Caribbean regional supranational binding-treaty framework operating formal Economic-Union framework + only modern Caribbean regional supranational binding-treaty framework operating formal monetary-union framework via Eastern Caribbean Currency Union ECCU + Eastern Caribbean Central Bank ECCB framework + only modern regional supranational binding-treaty framework operating formal 6-independent-states + 3-British-Overseas-Territories-mixed-membership framework + smallest regional supranational binding-treaty framework by population framework with ~600,000 combined population framework), as the central jurisdiction of the formal OECS Economic Union framework (OECS Revised Treaty Protocol on Economic Union providing formal Economic Union framework operating five freedoms: free movement of goods + services + capital + persons + harmonisation of fiscal + monetary + trade policies — formal foundational Eastern Caribbean Economic-Union framework, structurally distinctive globally as the only modern Eastern Caribbean regional supranational binding-treaty framework operating formal Economic-Union framework with five-freedoms framework), as the central jurisdiction of the formal Eastern Caribbean Currency Union ECCU framework (Eastern Caribbean Currency Union ECCU established 1965 + Eastern Caribbean Central Bank ECCB established 1 October 1983 in Basseterre Saint Kitts and Nevis providing formal Eastern Caribbean Dollar EC$ currency framework pegged to USD framework — formal foundational Eastern Caribbean Currency Union framework, structurally distinctive globally as the only modern Caribbean regional supranational binding-treaty framework operating formal monetary-union framework with Eastern Caribbean Dollar pegged to USD framework + only modern regional supranational binding-treaty framework operating formal 60-year-monetary-union framework), and as the central jurisdiction of the formal OECS Citizenship by Investment framework (OECS Citizenship by Investment CBI programmes effective from Saint Kitts and Nevis 1984 + Antigua and Barbuda 2013 + Dominica 1993 + Grenada 2013 + Saint Lucia 2015 — formal foundational Caribbean Citizenship-by-Investment framework, structurally distinctive globally as the only modern regional supranational binding-treaty framework operating formal multi-state-Citizenship-by-Investment framework + only modern Caribbean regional supranational binding-treaty framework operating formal Citizenship-by-Investment framework). The OECS Revised Treaty is binding upon 6 OECS member states + 4 OECS associate members as of 2026 (Antigua and Barbuda + Dominica + Grenada + Montserrat + Saint Kitts and Nevis + Saint Lucia + Saint Vincent and the Grenadines + 3 British Overseas Territories Anguilla + Martinique + British Virgin Islands) — comprehensive Eastern Caribbean regional coverage framework.
