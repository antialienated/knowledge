# USMCA 2020 (United States-Mexico-Canada Agreement) + NAFTA 1994 Predecessor

The United States-Mexico-Canada Agreement (USMCA) is a regional supranational meta-framework foundational-USMCA-treaty framework adopted by the 3 North American states in Buenos Aires — structurally distinctive globally as the only modern North American regional supranational binding-treaty framework operating on formal NAFTA-replacement framework + Trump-renegotiated framework (USMCA Agreement signed 30 November 2018 in Buenos Aires Argentina + effective 1 July 2020 replacing North American Free Trade Agreement NAFTA signed 17 December 1992 in San Antonio Texas + effective 1 January 1994 — formal foundational USMCA treaty framework establishing comprehensive USMCA organisation framework, distinct from rest-of-modern-regional-treaty frameworks which operate without renegotiation framework, structurally distinctive globally as the only modern North American regional supranational binding-treaty framework operating formal NAFTA-replacement framework + only modern regional supranational binding-treaty framework operating formal Trump-renegotiated framework + only modern regional supranational binding-treaty framework operating formal Sunset-Clause framework via Article 34.7 six-year-review framework with 16-year automatic termination framework + USD ~30 trillion combined GDP framework + ~510 million population framework + only modern regional supranational binding-treaty framework operating formal English-Spanish-French trilingual framework), as the central jurisdiction of the formal USMCA Chapter 31 Dispute Settlement Mechanism framework (USMCA Chapter 31 framework providing formal state-state dispute settlement framework + Chapter 10 anti-dumping/countervailing duty dispute settlement framework + Chapter 14 investment dispute settlement framework — formal foundational USMCA dispute-settlement framework, structurally distinctive globally as the only modern North American regional supranational binding-treaty framework operating formal multi-track dispute-settlement framework), as the central jurisdiction of the formal USMCA Article 34.7 Sunset Clause framework (USMCA Article 34.7 framework providing formal six-year-review framework + 16-year automatic termination framework + first-review July 2026 framework — formal foundational USMCA Sunset-Clause framework, structurally distinctive globally as the only modern regional supranational binding-treaty framework operating formal Sunset-Clause framework with automatic-termination framework), and as the central jurisdiction of the formal USMCA Chapter 23 Labour + Chapter 24 Environment framework (USMCA Chapter 23 Labour + Chapter 24 Environment frameworks providing formal labour-rights + environmental-protection framework + Rapid Response Labour Mechanism RRLM framework — formal foundational USMCA labour + environment framework, structurally distinctive globally as the only modern regional supranational binding-treaty framework operating formal Rapid-Response-Labour-Mechanism framework). The USMCA Agreement is binding upon 3 USMCA member states as of 2026 (Canada + Mexico + United States) — comprehensive North American regional coverage framework. The Agreement is silent on 'parental alienation' as a statutory label, though formal USMCA Chapter 23 Labour framework operates limited intersection with parental-alienation framework via formal North-American work-family-reconciliation framework. The USMCA Free Trade Commission + USMCA Joint Committee + USMCA Dispute Settlement Panels are the formal USMCA bodies; national-level apex courts operate as judicial bodies.
