# IMO Convention 1948 (International Maritime Organization)

The Convention on the International Maritime Organization (IMO Convention) is a global supranational meta-framework foundational-IMO-treaty framework adopted by the United Nations Maritime Conference in Geneva — structurally distinctive globally as the only modern global supranational binding-treaty framework operating on formal international-maritime-safety-pollution-and-security framework + foundational international shipping framework (IMO Convention adopted 6 March 1948 in Geneva Switzerland + effective 17 March 1958 + IMO operations began 17 March 1958 + originally Inter-Governmental Maritime Consultative Organization IMCO + renamed IMO 22 May 1982 — formal foundational IMO treaty framework establishing comprehensive IMO organisation framework, distinct from rest-of-modern-international-treaty frameworks which operate on different substantive areas, structurally distinctive globally as the only modern global supranational binding-treaty framework operating on formal international-maritime-safety-pollution-and-security framework + foundational international shipping framework + only modern global supranational binding-treaty framework operating formal SOLAS Convention on Safety of Life at Sea framework + only modern global supranational binding-treaty framework operating formal MARPOL Convention on Marine Pollution framework + only modern global supranational binding-treaty framework operating formal STCW Convention on Standards of Training Certification and Watchkeeping framework + only modern global supranational binding-treaty framework operating formal SUA Convention on Suppression of Unlawful Acts framework + only modern global supranational binding-treaty framework operating formal Net-Zero Greenhouse Gas Strategy 2023 framework + only modern global supranational binding-treaty framework operating formal Black Sea Grain Initiative 2022-2023 framework via IMO + UN-mediated framework via Russia + Ukraine grain-corridor framework), as the central jurisdiction of the formal IMO SOLAS Convention framework (SOLAS Safety of Life at Sea Convention adopted 1 November 1974 in London UK + effective 25 May 1980 + originally Titanic disaster 1912-response framework — formal foundational IMO SOLAS framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal maritime-safety framework with formal Titanic-1912-disaster-response framework), as the central jurisdiction of the formal IMO MARPOL Convention framework (MARPOL Convention for the Prevention of Pollution from Ships adopted 2 November 1973 in London UK + effective 2 October 1983 + 6 annexes including 2020 sulphur cap framework — formal foundational IMO MARPOL framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal marine-pollution-prevention framework), and as the central jurisdiction of the formal IMO Net-Zero Greenhouse Gas Strategy 2023 framework (IMO Revised Strategy on Reduction of GHG Emissions from Ships adopted 7 July 2023 at MEPC 80 + targets net-zero by 2050 + 20% by 2030 + 70% by 2040 framework + IMO Net-Zero Framework Agreement adopted 11 April 2025 at MEPC 83 framework — formal foundational IMO Net-Zero framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal maritime-net-zero-by-2050 framework + first major industry-wide net-zero framework). The IMO Convention is binding upon 175 IMO member states + 3 associate members as of 2026 — substantial universal coverage framework with notable non-members Liechtenstein + Andorra + Bhutan + Burkina Faso + Botswana + Burundi + Chad + Eswatini + Kyrgyzstan + Laos + Lesotho + Mali + Mongolia + Nepal + Niger + Rwanda + South Sudan + Tajikistan + Uganda + Uzbekistan + Zambia + Zimbabwe landlocked-states + Holy See + Liechtenstein + Andorra framework. The Convention is silent on 'parental alienation' as a statutory label, tho
