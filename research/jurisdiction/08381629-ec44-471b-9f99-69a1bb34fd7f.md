# CPTPP 2018 (Comprehensive and Progressive Agreement for Trans-Pacific Partnership)

The Comprehensive and Progressive Agreement for Trans-Pacific Partnership (CPTPP) is a regional supranational meta-framework foundational-CPTPP-treaty framework adopted by the 11 founding Pacific-Rim states in Santiago — structurally distinctive globally as the only modern trans-Pacific supranational binding-treaty framework operating on formal trans-Pacific-Rim framework + only modern regional supranational binding-treaty framework operating formal Trump-withdrawal-post-rescue framework via 22 TPP provisions suspended framework (CPTPP Agreement signed 8 March 2018 in Santiago Chile by Australia + Brunei + Canada + Chile + Japan + Malaysia + Mexico + New Zealand + Peru + Singapore + Vietnam + effective 30 December 2018 + Trans-Pacific Partnership TPP predecessor signed 4 February 2016 + US withdrew 23 January 2017 — formal foundational CPTPP treaty framework establishing comprehensive trans-Pacific framework, distinct from rest-of-modern-regional-treaty frameworks which operate without withdrawal-then-rescue framework, structurally distinctive globally as the only modern trans-Pacific supranational binding-treaty framework + only modern regional supranational binding-treaty framework operating formal Trump-withdrawal-post-rescue framework via 22 TPP provisions suspended framework + USD ~13 trillion combined GDP framework + ~600 million population framework + ~13% global GDP framework + 11 founding states + UK accession 15 December 2024 framework + Costa Rica + Indonesia + Philippines + Uruguay + Taiwan + China + Ecuador + Ukraine accession-applicants framework), as the central jurisdiction of the formal CPTPP 22 TPP Provisions Suspended framework (CPTPP Annex 2 framework providing formal 22 TPP provisions suspended framework primarily on Intellectual Property + investor-state dispute settlement narrowed framework — formal foundational CPTPP TPP-provisions-suspended framework, structurally distinctive globally as the only modern regional supranational binding-treaty framework operating formal predecessor-treaty-provisions-suspended framework), as the central jurisdiction of the formal CPTPP UK Accession 2023-2024 framework (UK signed CPTPP Accession Protocol 16 July 2023 in Auckland New Zealand + UK CPTPP membership effective 15 December 2024 — formal foundational CPTPP first-non-Pacific-Rim-state accession framework, structurally distinctive globally as the only modern trans-Pacific supranational binding-treaty framework operating formal non-Pacific-Rim-state accession framework + UK as first European CPTPP member framework + UK first non-original-CPTPP-signatory framework), and as the central jurisdiction of the formal CPTPP Investor-State Dispute Settlement narrowed framework (CPTPP Investor-State Dispute Settlement ISDS framework narrowed substantially from TPP framework + tobacco-control carve-out framework + financial-services carve-out framework — formal foundational CPTPP ISDS-narrowed framework, structurally distinctive globally as the only modern regional supranational binding-treaty framework operating formal ISDS-narrowed-from-predecessor-treaty framework). The CPTPP Agreement is binding upon 12 CPTPP member states as of 2026 (Australia + Brunei + Canada + Chile + Japan + Malaysia + Mexico + New Zealand + Peru + Singapore + Vietnam + UK) — comprehensive trans-Pacific + non-Pacific-Rim accession coverage framework. The Agreement is silent on 'parental alienation' as a statutory label, though formal CPTPP Chapter 19 Labour framework operates limited intersection with parental-alienation framework via formal trans-Pacific work-family-reconciliation framework. The CPTPP Commission + CPTPP Working Groups + CPTPP Dispute Settlement Panels are the formal CPTPP bodies; national-level apex courts operate as judicial bodies.
