# ICAO Chicago Convention 1944 (International Civil Aviation Organization)

The Convention on International Civil Aviation (ICAO Chicago Convention) is a global supranational meta-framework foundational-ICAO-treaty framework adopted by the 52 founding states in Chicago — structurally distinctive globally as the only modern global supranational binding-treaty framework operating on formal international-civil-aviation framework + foundational international aviation framework (ICAO Chicago Convention adopted 7 December 1944 in Chicago Illinois USA + effective 4 April 1947 + ICAO operations began 4 April 1947 — formal foundational ICAO treaty framework establishing comprehensive ICAO organisation framework, distinct from rest-of-modern-international-treaty frameworks which operate on different substantive areas, structurally distinctive globally as the only modern global supranational binding-treaty framework operating on formal international-civil-aviation framework + foundational international aviation framework + only modern global supranational binding-treaty framework operating formal Five Freedoms of the Air framework + only modern global supranational binding-treaty framework operating formal complete-and-exclusive-sovereignty-over-airspace framework via Chicago Convention Article 1 framework + only modern global supranational binding-treaty framework operating formal SARPs Standards and Recommended Practices framework + only modern global supranational binding-treaty framework operating formal MH17 + MH370 aviation accident-investigation framework + only modern global supranational binding-treaty framework operating formal Russian Federation-controversy 2022-2024 framework via ICAO Council decision not-to-relocate-Russia-IATA-codes 2024 framework), as the central jurisdiction of the formal ICAO SARPs Standards and Recommended Practices framework (ICAO SARPs framework providing formal Annexes 1-19 + PANS Procedures for Air Navigation Services framework — formal foundational ICAO SARPs framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal SARPs framework with 19 ICAO Annexes), as the central jurisdiction of the formal Chicago Convention Five Freedoms of the Air framework (Chicago Convention Five Freedoms of the Air framework providing formal First Freedom + Second Freedom + Third Freedom + Fourth Freedom + Fifth Freedom + Sixth-Ninth additional Freedoms framework — formal foundational Five Freedoms of the Air framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal Five Freedoms of the Air framework + traditional Nine Freedoms framework), and as the central jurisdiction of the formal ICAO CORSIA Carbon Offsetting and Reduction Scheme for International Aviation framework (ICAO CORSIA adopted 6 October 2016 + voluntary phase 2021-2026 + mandatory phase from 2027 framework — formal foundational ICAO CORSIA climate-mitigation framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal aviation-specific climate-mitigation framework). The ICAO Chicago Convention is binding upon 193 ICAO member states matching UN membership minus North Korea + Liechtenstein + 2-3 micro-states as of 2026 — substantial universal coverage framework. The Convention is silent on 'parental alienation' as a statutory label, though formal ICAO Annex 9 Facilitation Standards framework operates limited intersection with parental-alienation framework via formal aviation cross-border-children-traveler framework. The ICAO Assembly + ICAO Council + ICAO Secretary General + ICAO Air Navigation Commission + ICAO Air Transport Committee are the formal ICAO bodies; national-level apex courts operate as judicial bodies.
