# Mercosur Treaty of Asunción 1991 + Protocol of Ouro Preto 1994

The Mercosur Treaty of Asunción (Southern Common Market) is a regional supranational meta-framework foundational-Mercosur-treaty framework adopted by Argentina + Brazil + Paraguay + Uruguay in Asunción — structurally distinctive globally as the only modern South American regional supranational binding-treaty framework operating on formal Southern Cone common-market framework + Spanish-Portuguese bilingual framework (Treaty of Asunción signed 26 March 1991 in Asunción Paraguay by Argentina + Brazil + Paraguay + Uruguay + effective 29 November 1991 + Protocol of Ouro Preto signed 17 December 1994 granting Mercosur legal-personality framework + Mercosur Permanent Review Tribunal established 2002 — formal foundational Mercosur treaty framework establishing comprehensive Mercosur organisation framework, distinct from rest-of-modern-regional-treaty frameworks which operate on formal Anglophone or single-language frameworks, structurally distinctive globally as the only modern South American regional supranational binding-treaty framework operating formal Southern Cone common-market framework + only modern regional supranational binding-treaty framework operating formal Spanish-Portuguese bilingual treaty framework + intermediate-economic-bloc framework between free-trade-area + customs-union + common-market framework with operational customs-union framework), as the central jurisdiction of the formal Mercosur Customs Union framework (Treaty of Asunción Articles 1-8 framework providing formal common-external-tariff CET framework + formal intra-Mercosur free movement of goods framework + formal common-trade-policy framework — formal foundational Southern Cone customs-union framework, structurally distinctive globally as the only modern South American regional supranational binding-treaty framework operating formal customs-union framework), as the central jurisdiction of the formal Mercosur Permanent Review Tribunal framework (Olivos Protocol signed 18 February 2002 + effective 1 January 2004 establishing Mercosur Permanent Review Tribunal PRT based in Asunción Paraguay providing formal Mercosur dispute-settlement framework — formal foundational Mercosur dispute-settlement framework, structurally distinctive globally as the only modern South American regional supranational binding-treaty framework operating formal Mercosur dispute-settlement framework), and as the central jurisdiction of the formal Mercosur Democratic Clause framework (Ushuaia Protocol signed 24 July 1998 + Ushuaia II Protocol signed 20 December 2011 providing formal Mercosur democratic-clause framework — formal foundational Mercosur democratic-clause framework, structurally distinctive globally as the only modern South American regional supranational binding-treaty framework operating formal democratic-clause framework with operational suspension framework via Paraguay 2012-2013 + Venezuela 2016-2017). The Mercosur Treaty of Asunción is binding upon 5 Mercosur full-members Argentina + Brazil + Paraguay + Uruguay + Bolivia (full member effective 8 July 2024) + 7 associate members Chile + Colombia + Ecuador + Guyana + Peru + Suriname + Venezuela suspended-2017 as of 2026 — comprehensive Southern Cone coverage framework. The Treaty is silent on 'parental alienation' as a statutory label, though formal Mercosur Cooperation Agreement on Civil Matters framework operates substantial intersection with parental-alienation framework via formal Mercosur-regional cross-border-children's-rights framework. The Mercosur Common Market Council CMC + Mercosur Common Market Group GMC + Mercosur Trade Commission + Mercosur Parliament Parlasur + Mercosur Permanent Review Tribunal PRT are the formal Mercosur bodies; national-level apex courts operate as judicial bodies.
