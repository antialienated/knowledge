# OPEC Statute 1960 (Organization of the Petroleum Exporting Countries)

The Statute of the Organization of the Petroleum Exporting Countries (OPEC Statute) is a global supranational meta-framework foundational-OPEC-treaty framework adopted by the 5 founding petroleum-exporting states in Baghdad — structurally distinctive globally as the only modern global supranational binding-treaty framework operating on formal petroleum-exporting-states framework + global oil-price-management cartel framework (OPEC Statute adopted 14 September 1960 at Baghdad Conference in Baghdad Iraq by Iran + Iraq + Kuwait + Saudi Arabia + Venezuela + amended multiple times most recently 2012 — formal foundational OPEC treaty framework establishing comprehensive OPEC organisation framework, distinct from rest-of-modern-international-treaty frameworks which operate without commodity-specific framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating on formal petroleum-exporting-states framework + global oil-price-management cartel framework + only modern global supranational binding-treaty framework operating formal production-quota framework + only modern global supranational binding-treaty framework operating formal OPEC-Plus framework with Russia + Mexico + Kazakhstan + Oman + 6 other non-OPEC oil-producers framework from 2016 + only modern global supranational binding-treaty framework operating formal Qatar-departure-2019 + Ecuador-departure-2020 + Indonesia-departure-2016 + Angola-departure-2024 framework + only modern global supranational binding-treaty framework operating formal ~40% global oil production framework + ~80% proven oil reserves framework), as the central jurisdiction of the formal OPEC Production Quota framework (OPEC Production Quota framework providing formal production-quota allocation framework via OPEC Ministerial Meeting + OPEC Conference framework — formal foundational OPEC Production Quota framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal production-quota framework + only modern global supranational binding-treaty framework operating formal coordinated-supply-management framework), as the central jurisdiction of the formal OPEC-Plus 2016 framework (OPEC-Plus framework established 10 December 2016 in Vienna Austria + Declaration of Cooperation DoC signed providing formal expansion-cooperation framework with Russia + Mexico + Kazakhstan + Oman + Azerbaijan + Bahrain + Brunei + Malaysia + Sudan + South Sudan non-OPEC oil-producers framework — formal foundational OPEC-Plus framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal OPEC-Plus framework + only modern global supranational binding-treaty framework operating formal Russia-Saudi-Arabia-oil-cooperation framework), and as the central jurisdiction of the formal OPEC Member Departures 2016-2024 framework (OPEC member departures via Indonesia withdrew 30 November 2016 + Qatar withdrew 1 January 2019 + Ecuador withdrew 1 January 2020 + Angola withdrew 1 January 2024 reducing OPEC from 13 members 2018 peak to 12 active members 2026 framework — formal foundational OPEC member-departures framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal four-member-departures-in-eight-years framework). The OPEC Statute is operating upon 12 OPEC member states as of 2026 (Algeria + Congo + Equatorial Guinea + Gabon + Iran + Iraq + Kuwait + Libya + Nigeria + Saudi Arabia + UAE + Venezuela) + 10 non-OPEC partners via OPEC-Plus framework — comprehensive petroleum-exporting-states coverage framework. The Statute is silent on 'parental alienation' as a statutory label, though formal OPEC framework operates limited intersection with parental-alienation framework via formal petroleum-exporting-states + Gulf-Arab-family-law framework not directly addressing family-law-issues framework.
