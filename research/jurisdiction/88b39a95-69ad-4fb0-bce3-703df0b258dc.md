# Hague Convention 1961 on Apostille (Apostille Convention)

The Hague Convention 1961 on Apostille (popularly the Apostille Convention / formally Convention of 5 October 1961 Abolishing the Requirement of Legalisation for Foreign Public Documents) is a global supranational meta-framework cross-border-document-authentication binding-treaty instrument adopted by the Hague Conference on Private International Law (HCCH) — structurally distinctive globally as the only modern universal multilateral binding-treaty framework operating specifically on cross-border-document-authentication framework (Apostille Convention adopted 5 October 1961 in The Hague + effective 24 January 1965 — formal universal multilateral binding-treaty framework establishing comprehensive cross-border-document-authentication framework via formal Apostille certificate framework, distinct from rest-of-modern-international-cross-border-document frameworks which operate on bilateral or multilateral legalisation chain framework, structurally distinctive globally as the only modern universal binding-treaty framework operating on formal-cross-border-document-authentication-via-single-Apostille-certificate-specific framework with substantial relevance to PA framework via formal cross-border family-law documents authentication framework + cross-border marriage + divorce + child-custody + child-adoption documents authentication framework), as the central jurisdiction of the formal Article 1 public-documents framework (Apostille Convention Article 1 framework providing definition of 'public documents' including documents from a court authority + administrative documents + notarial acts + official certificates — formal foundational public-documents framework, structurally distinctive globally as the only modern universal binding-treaty framework operating formal public-documents framework including formal family-law documents framework), as the second-most-widely-ratified HCCH Convention framework alongside Hague Convention 1993 on Intercountry Adoption (Apostille Convention has 127 state parties as of 2026 — second-most-widely-ratified HCCH Convention framework alongside Hague Convention 1993, with substantial universal coverage framework + e-Apostille framework operational since 2007), and as the central jurisdiction of the formal e-Apostille framework (e-Apostille framework operational since 2007 — formal HCCH framework operating digital + cryptographic-authentication-of-Apostille framework, structurally distinctive globally as the only modern universal binding-treaty framework operating formal e-Apostille framework). The Apostille Convention is binding upon 127 state parties as of 2026 — second-most-widely-ratified HCCH Convention framework alongside Hague Convention 1993 on Intercountry Adoption framework. The Convention is silent on 'parental alienation' as a statutory label, though formal Article 1 public-documents framework operates substantial intersection with parental-alienation framework via formal cross-border family-law documents authentication framework + formal cross-border marriage + divorce + child-custody + child-adoption documents authentication framework. The Permanent Bureau of the Hague Conference on Private International Law is the apex monitoring framework body; national-level Competent Authorities operate as administrative bodies.
