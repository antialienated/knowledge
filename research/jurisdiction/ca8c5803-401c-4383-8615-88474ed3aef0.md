# Commonwealth Charter 2013 (Charter of the Commonwealth)

The Charter of the Commonwealth (Commonwealth Charter) is a regional supranational meta-framework foundational-Commonwealth-document framework adopted by the Commonwealth Heads of Government Meeting and signed by Queen Elizabeth II — structurally distinctive globally as the only modern voluntary association supranational framework operating on post-British-Empire framework with formal 16 Commonwealth core values framework via Commonwealth Charter framework (Commonwealth Charter signed 11 March 2013 in London by Queen Elizabeth II + Commonwealth founded 1949 via London Declaration adopting modern voluntary-association framework — formal foundational Commonwealth Charter framework operating non-treaty soft-law framework establishing 16 Commonwealth core values framework, distinct from rest-of-modern-regional-treaty frameworks which operate as formal binding-treaty frameworks, structurally distinctive globally as the only modern voluntary-association supranational framework operating non-treaty soft-law framework + only post-British-Empire framework + only modern regional supranational framework granting Republics-monarchies-mixed-membership framework), as the central jurisdiction of the formal Commonwealth Charter 16 Core Values framework (Commonwealth Charter 16 Commonwealth core values framework: democracy + human rights + international peace and security + tolerance respect and understanding + freedom of expression + separation of powers + rule of law + good governance + sustainable development + protecting the environment + access to health education food and shelter + gender equality + importance of young people in the Commonwealth + recognition of the needs of small states + recognition of the needs of vulnerable states + the role of civil society — formal foundational Commonwealth core-values framework, structurally distinctive globally as the only modern voluntary-association supranational framework operating formal 16 Commonwealth core values framework), as the central jurisdiction of the formal Commonwealth Ministerial Action Group CMAG framework (Commonwealth Ministerial Action Group CMAG established 1995 at Auckland CHOGM providing formal Commonwealth membership-suspension framework over violation of Commonwealth core values — formal foundational Commonwealth membership-suspension framework, structurally distinctive globally as the only modern voluntary-association supranational framework operating formal membership-suspension framework with operational suspension framework via Nigeria 1995-1999 + Pakistan 1999-2004 + 2007-2008 + Zimbabwe 2002-2003 + Fiji 2009-2014), and as the central jurisdiction of the formal Commonwealth of Nations 1949 London Declaration framework (London Declaration adopted 28 April 1949 in London by the Commonwealth Prime Ministers' Conference providing formal abandonment of British Commonwealth framework + adoption of voluntary Commonwealth of Nations framework + acceptance of Republics-monarchies-mixed-membership framework — formal foundational modern Commonwealth voluntary-association framework, structurally distinctive globally as the only modern regional supranational framework operating formal post-British-Empire Republics-monarchies-mixed-membership framework). The Commonwealth Charter is operating upon 56 Commonwealth member states as of 2026 — comprehensive post-British-Empire coverage framework (Maldives rejoined 1 February 2020 after 2016 withdrawal + Gabon + Togo joined 2022 as first non-British-Empire members + Rwanda 2009 + Mozambique 1995 framework). The Charter is silent on 'parental alienation' as a statutory label, though formal Commonwealth Charter 16 core values framework operates substantial intersection with parental-alienation framework via formal cross-border-Commonwealth-children's-rights framework underlying Commonwealth common-law family-court tradition.
