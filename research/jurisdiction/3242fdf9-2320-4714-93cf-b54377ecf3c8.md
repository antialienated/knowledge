# EAEU Treaty 2014 (Eurasian Economic Union)

The Treaty on the Eurasian Economic Union (EAEU Treaty) is a regional supranational meta-framework foundational-EAEU-treaty framework adopted by the 3 founding Russia + Kazakhstan + Belarus states in Astana — structurally distinctive globally as the only modern post-Soviet regional supranational binding-treaty framework operating on formal post-Soviet integration framework + only modern regional supranational binding-treaty framework operating formal Russia-led-economic-integration framework (EAEU Treaty signed 29 May 2014 in Astana Kazakhstan by Belarus + Kazakhstan + Russia + effective 1 January 2015 + Eurasian Customs Union ECU predecessor founded 1 January 2010 + Eurasian Economic Community EurAsEC predecessor founded 10 October 2000 — formal foundational EAEU treaty framework establishing comprehensive EAEU organisation framework, distinct from rest-of-modern-regional-treaty frameworks which operate on different geographic scopes, structurally distinctive globally as the only modern post-Soviet regional supranational binding-treaty framework operating formal post-Soviet integration framework + only modern regional supranational binding-treaty framework operating formal Russia-led-economic-integration framework + EAEU operating formal customs-union + common-market + planned-monetary-union framework + ~3.2 trillion combined GDP framework + ~180 million population framework + only modern regional supranational binding-treaty framework operating formal post-Russia-invasion-of-Ukraine western-sanctions-encirclement framework + only modern regional supranational binding-treaty framework operating formal CSTO-collective-security-overlap framework), as the central jurisdiction of the formal EAEU Court framework (Court of the Eurasian Economic Union established 1 January 2015 in Minsk Belarus providing formal EAEU judicial framework with individual-petition framework via Article 39 EAEU Treaty for natural + legal persons — formal foundational EAEU judicial framework, structurally distinctive globally as the only modern post-Soviet regional supranational binding-treaty framework operating formal individual-petition court framework + first modern post-Soviet regional supranational court operating formal individual-petition framework), as the central jurisdiction of the formal EAEU Customs Union + Common Market framework (EAEU Customs Union effective from EurAsEC 1 January 2010 + EAEU Common Market effective from 1 January 2012 providing formal four-freedoms framework: free movement of goods + services + capital + labour — formal foundational EAEU customs-union + common-market framework, structurally distinctive globally as the only modern post-Soviet regional supranational binding-treaty framework operating formal customs-union + common-market framework + only modern post-Soviet regional supranational binding-treaty framework operating formal four-freedoms framework), and as the central jurisdiction of the formal EAEU Free Trade Agreements + Greater Eurasian Partnership framework (EAEU Free Trade Agreements with Vietnam 2015 + Singapore 2019 + Serbia 2019 + Iran 2018 Interim Agreement upgraded 2023 Free Trade Agreement + China Trade and Economic Cooperation Agreement 2018 + Greater Eurasian Partnership framework — formal foundational EAEU Free Trade Agreements + Greater Eurasian Partnership framework, structurally distinctive globally as the only modern post-Soviet regional supranational binding-treaty framework operating formal EAEU Free Trade Agreements + Greater Eurasian Partnership framework). The EAEU Treaty is binding upon 5 EAEU member states as of 2026 (Armenia + Belarus + Kazakhstan + Kyrgyzstan + Russia) + 3 observer states Cuba + Moldova + Uzbekistan — comprehensive post-Soviet regional coverage framework. The Treaty is silent on 'parental alienation' as a statutory label, though formal EAEU four-freedoms framework operates substantial intersection with parental-alienation framework via formal post-Soviet cross-border-chi
