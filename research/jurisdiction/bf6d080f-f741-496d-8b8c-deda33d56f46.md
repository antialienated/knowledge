# CAN Cartagena Agreement 1969 (Andean Community)

The Cartagena Agreement (CAN Andean Community Cartagena Agreement) is a regional supranational meta-framework foundational-CAN-treaty framework adopted by the 5 founding Andean states in Cartagena — structurally distinctive globally as the oldest modern South American regional supranational binding-treaty framework operating on formal Andean-integration framework + only modern South American regional supranational binding-treaty framework operating formal Andean Court of Justice framework (CAN Cartagena Agreement signed 26 May 1969 in Bogotá Colombia by Bolivia + Chile + Colombia + Ecuador + Peru + effective 16 October 1969 + Trujillo Protocol signed 10 March 1996 in Trujillo Peru transforming CAN organisation framework — formal foundational CAN treaty framework establishing comprehensive CAN organisation framework, distinct from rest-of-modern-regional-South-American-treaty frameworks which operate without Andean specificity, structurally distinctive globally as the oldest modern South American regional supranational binding-treaty framework + only modern South American regional supranational binding-treaty framework operating formal Andean-integration framework + only modern South American regional supranational binding-treaty framework operating formal Andean Court of Justice framework + only modern regional supranational binding-treaty framework operating formal Chile-Venezuela-major-departure framework via Chile withdrew 1976 + Venezuela withdrew 22 April 2011 framework + only modern regional supranational binding-treaty framework operating formal Andean Parliament framework via Andean Parliament 1979), as the central jurisdiction of the formal CAN Andean Court of Justice framework (Court of Justice of the Andean Community CAN Court established 28 May 1979 in Quito Ecuador providing formal CAN judicial framework with individual-petition framework via Article 31 Treaty Creating the Court — formal foundational CAN judicial framework, structurally distinctive globally as the only modern South American regional supranational binding-treaty framework operating formal individual-petition court framework + only modern South American regional supranational binding-treaty framework operating formal supranational court framework), as the central jurisdiction of the formal CAN Free Trade Area + Customs Union framework (CAN Andean Free Trade Area operational from 1969 + CAN Common External Tariff CET effective from 1995 + CAN Common Market intended framework — formal foundational Andean free-trade + customs-union framework, structurally distinctive globally as the only modern South American regional supranational binding-treaty framework operating formal Andean customs-union framework), and as the central jurisdiction of the formal CAN Decision 583 Andean Migration framework (CAN Decision 583 of 7 May 2004 + CAN Decision 545 Andean Migration Instrument 2003 providing formal Andean free-movement-of-persons framework — formal foundational Andean free-movement-of-persons framework, structurally distinctive globally as the only modern South American regional supranational binding-treaty framework operating formal Andean free-movement-of-persons framework with operational Andean Migration Card framework). The CAN Cartagena Agreement is binding upon 4 CAN member states as of 2026 (Bolivia + Colombia + Ecuador + Peru) + 5 CAN associate members (Argentina + Brazil + Chile + Paraguay + Uruguay) + 2 CAN observer states + Chile withdrew 1976 + Venezuela withdrew 22 April 2011 framework — comprehensive Andean regional coverage framework. The Agreement is silent on 'parental alienation' as a statutory label, though formal CAN Decision 583 Andean Migration framework operates substantial intersection with parental-alienation framework via formal Andean cross-border-children's-rights framework + free-movement-of-persons framework.
