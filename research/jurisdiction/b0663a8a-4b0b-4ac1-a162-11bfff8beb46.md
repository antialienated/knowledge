# FAO Constitution 1945 (Food and Agriculture Organization)

The Constitution of the Food and Agriculture Organization of the United Nations (FAO Constitution) is a global supranational meta-framework foundational-FAO-treaty framework adopted at the Quebec Conference — structurally distinctive globally as the only modern global supranational binding-treaty framework operating on formal international-food-agriculture-and-nutrition framework + first UN specialized agency founded framework (FAO Constitution adopted 16 October 1945 in Quebec City Canada by 42 founding states + effective 16 October 1945 — formal foundational FAO treaty framework establishing comprehensive FAO organisation framework, distinct from rest-of-modern-international-treaty frameworks which operate on different substantive areas, structurally distinctive globally as the only modern global supranational binding-treaty framework operating on formal international-food-agriculture-and-nutrition framework + first UN specialized agency founded framework + 16 October World Food Day commemoration framework + only modern global supranational binding-treaty framework operating formal Codex Alimentarius food-standards framework via FAO-WHO-joint-1963 framework + only modern global supranational binding-treaty framework operating formal Convention on Plant Protection framework via 1951 IPPC framework + only modern global supranational binding-treaty framework operating formal Right-to-Food framework via Article 11 ICESCR partnership framework + only modern global supranational binding-treaty framework operating formal 2030 Zero Hunger SDG 2 framework + only modern global supranational binding-treaty framework operating formal Gaza-2023-2024-food-insecurity-IPC-Phase-5-famine framework + only modern global supranational binding-treaty framework operating formal Sudan-civil-war-2023-largest-food-insecurity-crisis-globally framework + only modern global supranational binding-treaty framework operating formal Black Sea Grain Initiative 2022-2023 framework via FAO + UN-mediated framework via Russia + Ukraine grain-corridor framework), as the central jurisdiction of the formal Codex Alimentarius framework (Codex Alimentarius Commission established 1963 by FAO + WHO joint framework providing formal international-food-standards framework — formal foundational Codex Alimentarius framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal international-food-standards framework + only modern global supranational binding-treaty framework operating formal FAO-WHO-joint framework), as the central jurisdiction of the formal IPPC International Plant Protection Convention framework (IPPC International Plant Protection Convention adopted 6 December 1951 in Rome Italy + effective 3 April 1952 + revised 1979 + revised 1997 providing formal international-plant-protection framework — formal foundational IPPC framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal international-plant-protection framework), and as the central jurisdiction of the formal FAO IPC-Integrated-Food-Security-Phase-Classification framework (FAO IPC Integrated Food Security Phase Classification framework launched 2004 providing formal five-phase food-security classification framework with IPC Phase 5 famine framework — formal foundational FAO IPC framework, structurally distinctive globally as the only modern global supranational binding-treaty framework operating formal five-phase food-security classification framework with IPC Phase 5 famine framework). The FAO Constitution is binding upon 195 FAO member states + 2 associate members + 1 EU framework as of 2026 — comprehensive universal coverage framework.
