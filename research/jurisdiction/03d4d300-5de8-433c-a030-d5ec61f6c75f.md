# COMESA Treaty 1993 (Common Market for Eastern and Southern Africa)

The Treaty Establishing the Common Market for Eastern and Southern Africa (COMESA Treaty) is a regional supranational meta-framework foundational-COMESA-treaty framework adopted by the 22 African states in Kampala — structurally distinctive globally as the largest modern African regional supranational binding-treaty framework operating on formal Cape-to-Cairo coverage framework (COMESA Treaty signed 5 November 1993 in Kampala Uganda + effective 8 December 1994 + PTA Preferential Trade Area for Eastern and Southern African States predecessor founded 21 December 1981 in Lusaka Zambia — formal foundational COMESA treaty framework establishing comprehensive COMESA organisation framework, distinct from rest-of-modern-regional-African-treaty frameworks which operate on smaller geographic scopes, structurally distinctive globally as the largest modern African regional supranational binding-treaty framework + only modern African regional supranational binding-treaty framework operating formal Cape-to-Cairo coverage framework spanning Egypt to Eswatini + 21 African states ratification framework + English-French-Arabic-Portuguese quadrilingual framework + most-overlapping-membership framework with EAC + SADC + IGAD + AfCFTA framework), as the central jurisdiction of the formal COMESA Court of Justice CCJ framework (COMESA Court of Justice established 7 December 1998 in Khartoum Sudan + relocated to Lusaka Zambia 2003 + relocated to Khartoum Sudan 2008 providing formal COMESA judicial framework with individual-petition framework via Article 26 COMESA Treaty — formal foundational COMESA judicial framework, structurally distinctive globally as the only modern East-and-Southern-African regional supranational binding-treaty framework operating formal individual-petition framework via direct-access framework after exhaustion-of-local-remedies framework), as the central jurisdiction of the formal COMESA Free Trade Area FTA framework (COMESA Free Trade Area FTA launched 31 October 2000 in Lusaka Zambia by Djibouti + Egypt + Kenya + Madagascar + Malawi + Mauritius + Sudan + Zambia + Zimbabwe + 9 additional states joined FTA framework — formal foundational COMESA Free-Trade-Area framework, structurally distinctive globally as the only modern East-and-Southern-African regional supranational binding-treaty framework operating formal Free-Trade-Area framework + first African regional FTA framework), and as the central jurisdiction of the formal Tripartite Free Trade Area TFTA framework + AfCFTA-precursor framework (COMESA + EAC + SADC Tripartite Free Trade Area TFTA signed 10 June 2015 in Sharm El-Sheikh Egypt providing formal Cape-to-Cairo TFTA framework + COMESA-EAC-SADC African Continental Free Trade Area AfCFTA-precursor framework — formal foundational COMESA TFTA + AfCFTA-precursor framework, structurally distinctive globally as the only modern African regional supranational binding-treaty framework operating formal Tripartite-Free-Trade-Area framework + only modern African regional framework operating formal AfCFTA-precursor framework). The COMESA Treaty is binding upon 21 COMESA member states as of 2026 (Burundi + Comoros + DRC + Djibouti + Egypt + Eritrea + Eswatini + Ethiopia + Kenya + Libya + Madagascar + Malawi + Mauritius + Rwanda + Seychelles + Somalia + Sudan + Tunisia + Uganda + Zambia + Zimbabwe) + 3 dialogue partners as of 2026 — comprehensive Cape-to-Cairo regional coverage framework + Tanzania withdrew 2 September 2000 + Lesotho withdrew 1997 + Mozambique withdrew 1997 framework. The Treaty is silent on 'parental alienation' as a statutory label, though formal COMESA Court of Justice individual-petition framework operates substantial intersection with parental-alienation framework via formal Cape-to-Cairo regional cross-border-children's-rights framework via individual-petition framework.
